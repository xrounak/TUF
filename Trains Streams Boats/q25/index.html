Trains, Streams and Boats
A boat covers 48 km upstream in 4 hours while the stream flows at 3 km/h. What is the boat's speed in still water?
Q
Given
Upstream distance = 48 km, time = 4 h, stream = 3 km/h. Find boat's speed in still water.
Stream = 3 km/h
Given
Distance = 48 km, Time = 4 h
Stream speed = 3 km/h
Let Boat = B, Stream = C
Step 1
Upstream Speed = Boat − Stream
= B − C
Speed = DistanceTime
484 = 12 km/h
Step 2
B − C = 12
C = 3
B − 3 = 12
B = 15 km/h
