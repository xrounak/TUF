Trains, Streams and Boats
The ratio of a boat's still-water speed to stream speed is 5:1. If it takes 4 hours to go downstream, how long will it take to return upstream over the same distance?
Q
Given
Still-water : Stream = 5 : 1. Downstream time = 4 h. Find upstream time.
Let
Still-water : Stream = 5 : 1
Given
Ratio = 5 : 1
Downstream time = 4 h
Boat speed = 5x
Stream speed = x
Step 1
Downstream speed = Boat + Stream
Upstream speed = Boat − Stream
5x + x = 6x
5x − x = 4x
Step 2
Distance = Speed × Time
6x × 4 = 24x
Upstream distance = 24x (same)
Step 3
Time = DistanceSpeed
24x4x
x cancels = 6 h
G
