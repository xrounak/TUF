Question:
A bus has a running speed of 54 km/hr and stops for 8 minutes in every hour. What is its average speed including stops?

Options:
A. 45 km/hr
B. 48 km/hr
C. 50 km/hr
D. 46.8 km/hr

Correct Option: D

Solution:
Given values:
Running Speed = 54 km/hr
Stop Time = 8 min every hour

In every one hour, the bus stops for 8 minutes. So out of every 60 minutes, it is actually moving for only 52 minutes.

Step 1: Find the actual running time.
Running time = 60 - 8 = 52 min

Step 2: Find the distance covered during these 52 minutes.
Distance = Speed x Time
Speed = 54 km/hr
Time = 52/60 hr

Distance = 54 x (52/60)
= 46.8 km

Step 3: Find the average speed.
In this 1 hr (with the stop), Distance = 46.8 km.
Since Time = 1 hour, and average speed means how much distance is covered in one full hour:
Average Speed = 46.8 km/hr

So the average speed of the bus including stops is 46.8 km/hr.

Hence, the correct answer is Option D.
