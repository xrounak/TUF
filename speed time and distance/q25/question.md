Question:
A delivery van travels for 2 hours at 45 km/hr and then for 3 hours at 60 km/hr. Find the average speed.

Options:
A. 52 km/hr
B. 56 km/hr
C. 54 km/hr
D. 50 km/hr

Correct Option: C

Solution:
Given: Part 1: Time = 2 hr, Speed = 45 km/hr. Part 2: Time = 3 hr, Speed = 60 km/hr.

Step 1: Find the distance covered in each part using Distance = Speed x Time.
Part 1: Distance = 45 x 2 = 90 km
Part 2: Distance = 60 x 3 = 180 km

Step 2: Find the total distance.
Total Distance = 90 + 180 = 270 km

Step 3: Find the total time.
Total Time = 2 hr + 3 hr = 5 hours

Step 4: Find the average speed.
Average Speed = Total Distance / Total Time
= 270 / 5
= 54 km/hr

So the average speed of the delivery van is 54 km/hr. Hence, the correct answer is Option C, 54 km/hr.
