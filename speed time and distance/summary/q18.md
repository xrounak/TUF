Let the distance between the home and the office be x km.

Step 1: Time for each leg of the journey
Time = Distance / Speed
Time (Going) = x / 54 hr
Time (Return) = x / 36 hr

Step 2: Total distance and total time
Total Distance = x + x = 2x km
Total Time = x/54 + x/36
Simplifying this, Total Time = 5x/108 hr

Step 3: Average speed
Average Speed = Total Distance / Total Time
= 2x / (5x/108)
Dividing by a fraction is the same as multiplying by its reciprocal, so this becomes:
= 2x x 108/5x
The x cancels out.
= 216/5
= 43.2 km/hr

So the average speed for the complete round trip is 43.2 km/hr.
Hence, the correct answer is Option A.
