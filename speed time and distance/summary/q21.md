Given: Ratio of speeds (A : B) = 5 : 6, A's time to cover the distance = 72 min.

Let speed of A = 5x and speed of B = 6x.

Step 1: Find the common distance.
Distance = Speed x Time
For A: Distance = 5x x 72 = 360x
Since both A and B cover the same distance, B's distance is also 360x.

Step 2: Find B's time.
Time = Distance / Speed = 360x / 6x
The x cancels out from numerator and denominator.
Time = 60 minutes

So B takes 60 minutes to cover the same distance. Hence, the correct answer is Option B, 60 minutes.
