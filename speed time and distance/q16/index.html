Given
Slower = 18 km/hr
Faster = x km/hr
Time = 3 hr
Gap = 27 km
Step 1
Distance = Speed × Time
Slower: 18 × 3 = 54 km
Faster: x × 3 = 3x km
Step 2
27 km ahead → faster covers 27 km more
Faster distance − Slower distance = 27
3x − 54 = 27
Step 3
3x − 54 = 27
3x = 27 + 54 = 81
x = 81 ÷ 3 = 27 km/hr
