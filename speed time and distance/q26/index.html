A train covers 300 km in 5 hours, including stoppages. If its running speed is 75 km/hr, find the total stoppage time.
Q
❚❚
?
Total: 300 km in 5 hr

Train covers 300 km in 5 hr (incl. stoppages). Running speed = 75 km/hr. Find stoppage time.
❚❚
300km/5hr → 75 km/hr run
Given
Total Distance = 300 km
Total Time = 5 hr
Running Speed = 75 km/hr
Let's find the actual running time
Step 1
Time = Distance / Speed
Running Time = 300 / 75
= 4 hours
Total = 5 hr,
Moving = 4 hr → remaining is stoppage
Step 2
Stoppage Time = Total Time − Running Time
= 5 − 4
= 1 hour
