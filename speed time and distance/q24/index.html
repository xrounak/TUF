Speed, Time and Distance
For the same route, the times taken by two cars are in the ratio 4 : 5. What is the ratio of their speeds?
Q
Time = 4y hrs
Route = x km
Time = 5y hrs
Same route, time ratio 4 : 5. Find the speed ratio.
x km · 4y & 5y hrs
Given
Time ratio = 4 : 5
Same route → same distance
Distance = x km
Time A = 4y hrs, Time B = 5y hrs
Step 1
Speed = Distance ÷ Time
Speed A = x4y
Speed B = x5y
Step 2
Speed ratio = x4y : x5y
Divide first fraction by second
= x4y × 5yx
x cancels, y cancels
= 54
Speed ratio = 5 : 4
G

Time A = 4y, Time B = 5y hrs

2
