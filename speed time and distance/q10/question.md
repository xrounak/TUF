Question:
A car covers two equal distances — the first at 40 km/hr, the second at 60 km/hr. What is the average speed for the whole journey?

Options:
A. 45 km/hr
B. 50 km/hr
C. 52 km/hr
D. 48 km/hr

Correct Option: D

Solution:
Since both distances are equal, let each distance be x km.

We know the formula: Time = Distance / Speed

Time taken to cover the first part = x / 40 hr
Time taken to cover the second part = x / 60 hr

Total Time = x/40 + x/60
= x/24 hr

Total Distance = x + x = 2x km

Now apply the average speed formula.
Average Speed = Total Distance / Total Time

Putting the values:
Average Speed = 2x / (x/24)

The x cancels out, leaving:
= 2 x 24
= 48 km/hr

So the average speed for the whole journey is 48 km/hr.

Hence, the correct answer is Option D.
