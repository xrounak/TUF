Question:
A traveller covers half of a route at 48 km/hr and the other half at 72 km/hr. Find the average speed.

Options:
A. 54 km/hr
B. 56 km/hr
C. 60 km/hr
D. 57.6 km/hr

Correct Option: D

Solution:
Let the total distance be x km.
Since the journey is divided into two equal halves, each half is x/2 km.

Step 1: Time for the first half
Time = Distance / Speed
Time for first half = (x/2) / 48 = x/96 hrs

Step 2: Time for the second half
Time for second half = (x/2) / 72 = x/144 hrs

Step 3: Total time
Total time = x/96 + x/144 = 5x/288 hrs

Step 4: Average speed
Average speed = Total distance / Total time
= x / (5x/288)
The x cancels out.
= 288 / 5
= 57.6 km/hr

So the average speed of the traveller is 57.6 km/hr.
Hence, the correct answer is Option D.
