Half the route at 48 km/hr, rest at 72 km/hr — find the average speed.
48 km/hr → 72 km/hr
Given
Let total distance = x km
Each half = x/2 km
Step 1
Finding time for each half
Time = DistanceSpeed
x/248 = x96 hrs
Step 2
Finding time for the second half
= x/272 = x144 hrs
Step 3
Adding both times
x/96 + x/144 = 5x288 hrs
Step 4
Average speed = Total distanceTotal time
= x5x/288
x cancels
= 2885
= 57.6 km/hr
