But distance is given in mee-ter, and time is given in minutes and seconds.
So first, we need to convert the time into seconds.

8 minutes means 8 into 60, which is 480 seconds.
And 20 seconds is already there.

So total time becomes 480 pluss 20, equal to 500 seconds.
Done.

Now put the values in the speed formula.

Speed equal to distance divided by time, which is 800 divided by 500.
After simplifying this, we get 1.6 mee-ter per second.

But the question is asking in kilo-mee-ter per hour.
So we need to convert mee-ter per second into kilo-mee-ter per hour.
For that, we multiply it by 3.6.

So speed becomes 1.6 into 3.6, which is 5.76 kilo-mee-ter per hour.
