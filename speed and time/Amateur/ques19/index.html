In a 900 km flight, bad weather reduced the average speed by 300 km/hr and increased time by 30 minutes. The original duration is:
Q
900 km

900 km flight, speed reduced by 300 km/hr, time up by 30 min. Original duration?
900 km
Given
Distance = 900 km
Speed reduced by = 300 km/hr
Extra time = 0.5 hr
Step 1
Let speed = x km/hr
Original time = 900x
New speed = (x − 300) km/hr
New time = 900x − 300
Step 2
New time = Original time + 0.5
900x − 300 = 900x + 0.5
x² − 300x − 540000 = 0
Step 3
(x − 900)(x + 600) = 0
x = 900 or x = −600
Speed ≠ negative → x = 900 km/hr
Step 4
Original time = 900900
= 1 hour
